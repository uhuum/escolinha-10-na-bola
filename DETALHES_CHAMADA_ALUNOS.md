# Detalhes da chamada — alunos

Correção da rota **Ver Detalhes** da chamada.

- A lógica que usa hooks foi movida para um Client Component real, evitando a página de detalhes quebrada.
- Presentes e ausentes agora exibem foto, nome completo e turma/horário.
- Cada aluno é clicável e abre o perfil completo dele no SIGA.
- A tela possui estado de carregamento e mensagem profissional caso o registro não seja encontrado.
- Layout responsivo para celular e computador.
